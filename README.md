# TaskFlow – Task Management Application

## About the Project

TaskFlow is a full-stack task management application built using React, Node.js, Express.js and MySQL.

It helps users organize their daily tasks and track their progress.

## Features

- Add new tasks
- Edit tasks
- Delete tasks
- Mark tasks as completed
- Set task priority (Low, Medium, High)
- Set due dates
- Search tasks
- Filter pending and completed tasks
- Track task progress
- View overdue tasks

## Technologies Used

**Frontend**
- React.js
- JavaScript
- HTML
- CSS
- Vite

**Backend**
- Node.js
- Express.js

**Database**
- MySQL

## Project Structure

- `task-manager` – Frontend
- `backend` – Backend

## How to Run

### Backend

```bash
cd backend
npm install
node server.js
```

### Frontend

```bash
cd task-manager
npm install
npm run dev
```

## Database

Create a MySQL database named `taskflow` and configure the database connection in the backend.
